# Final Submission Checklist

## Code

- API starts successfully.
- /health works.
- /ask works.
- /feedback works.
- /metrics works.
- /dashboard works.
- Evaluation script runs.

## Files

- README exists.
- Demo docs exist.
- Evaluation results exist.
- Dockerfile exists.
- render.yaml exists.
- Azure deployment guide exists.
- Support portal demo exists.

## Security

- .env exists locally but is not committed.
- .env.example exists.
- logs/ is ignored.
- **pycache**/ is ignored.
- API key is used for protected endpoints.

## Demo

- Open README.
- Show project summary.
- Start API.
- Show /health.
- Ask a question.
- Show dashboard.
- Send feedback.
- Show metrics.
- Show evaluation report.
- Show deployment files.

## Before Git Push

- Run git status.
- Confirm .env is not staged.
- Confirm logs/ is not staged.
- Confirm **pycache**/ is not staged.
- Commit with a clear message.
