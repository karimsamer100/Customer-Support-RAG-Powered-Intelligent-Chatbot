# Business KPI Impact

| KPI | Expected Impact from Chatbot |
|---|---|
| First Response Time | Reduced by automated immediate answers to common questions |
| Ticket Deflection Rate | Increased as common queries are resolved without agent involvement |
| Agent Productivity | Improved by reducing time spent on repetitive queries |
| Customer Satisfaction | Improved through faster, consistent responses |
| Support Cost | Reduced due to lower agent load and faster resolutions |

Each KPI can be instrumented and measured as part of an evaluation plan; use evaluation outputs and production telemetry to quantify real impact.
