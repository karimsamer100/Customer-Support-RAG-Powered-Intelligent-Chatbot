# Future Work

These items are future enhancements and are not implemented in the current demo codebase:

- Add FAQ/manual/knowledge base documents and index them into the vector store.
- Add LangChain-style conversation memory or custom conversation memory to support multi-turn context.
- Deploy to Azure App Service as a production option.
- Integrate Azure AD authentication for enterprise access control.
- Add MLflow experiment tracking for model/configuration comparisons.
- Add a monitoring dashboard (Application Insights, Prometheus + Grafana) for latency and error tracking.
- Schedule automatic embedding refresh and re-indexing when new support data arrives.
- Integrate a human feedback loop and online evaluation for continuous improvement.
- Expand evaluation with human scoring and more sophisticated metrics.

These enhancements are recommended next steps for a production-grade system but are outside the scope of this quick demo.
